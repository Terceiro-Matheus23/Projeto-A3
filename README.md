# Projeto-A3
# Passos iniciais
Abra o codespace pelo github
Abra um novo terminal e nele digite

# 1. Puxe as atualizações
git pull origin main

# 2. Inicie o site
python -m http.server 8000

# 3. Abra o navegador (Chrome, Edge, etc.) e digite este endereço na barra superior:
http://localhost:8000/coffee.html

# 1. Para adicionar todas as alterações feitas
git add .

# 2. Salva a versão com uma mensagem explicativa
git commit -m "escreva as modificações feitas"

# 3. Enviar as alterações para o GitHub
git push origin main
